# Security policy

Please do not open public issues for suspected vulnerabilities that could affect
users, their repositories, credentials, or local environments. Report them
privately to the repository owner through the contact route on the
[GitHub profile](https://github.com/luingry), including a minimal reproduction,
affected files or versions, impact, and any safe mitigation.

This repository is maintained on a best-effort basis. Please allow time for
triage before public disclosure.
