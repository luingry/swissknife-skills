# Direction and Craft

Start with the product and task, not a generic visual trend. Form a short
direction and thesis around the hierarchy, density, tone, and interaction
emphasis that serve this user in this context. For an open brief, consider two
or three genuinely distinct directions internally, then choose one; no report
is required unless a handoff or coordination benefits from it.

For an existing product, preserve recognizable patterns, information
architecture, tokens, interaction behavior, and adjacent-surface continuity.
For greenfield or redesign, establish the audience, task, information
hierarchy, and product-specific visual logic before repeating components.

Typography and composition are structural: use them to make the next useful
action and important information clear. Let spacing, alignment, contrast, and
semantic grouping work before decorative containers. Component libraries supply
primitives, not identity.

High-frequency patterns such as repeated cards, nested containers, pills,
hero gradients, and generic metric tiles need a product-specific reason. These
are examples requiring justification, never a blacklist.

Run the anti-convergence test: after removing brand marks and copy, would the
composition still feel deliberately suited to this product and task? If not,
make a more grounded choice. This is a prompt for justification, never a
blacklist or mandate for a new aesthetic.
