# References and Concepts

User-provided and project-local references outrank external inspiration. Inspect
only the references that can answer a real decision: hierarchy, interaction,
tone, density, or responsive behavior. Extract transferable principles; do not
copy a competitor's composition, assets, or distinctive expression.

Use web research sparingly when the expected design value outweighs the cost or
uncertainty. Keep the source set small and record only the principles that
change the work.

For high-value, open greenfield or flagship work, a rough concept may help
compare directions. Image generation is optional, not required, and should not
replace practical UI implementation or verification. Do not use it for routine
refinement, constrained product work, or low-value visual exploration.
