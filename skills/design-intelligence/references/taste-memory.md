# Taste Memory

`~/.agents/design-taste.md` is a small global memory for durable,
explicitly supplied preferences. It is subordinate to the current brief and to
the project. Read it only for significant visual work.

Keep three scopes distinct:

- **Universal:** broadly applicable accessibility or craft principles.
- **Global:** durable preferences explicitly supplied by the user.
- **Project:** identity, tokens, conventions, and audience context belonging to
  one product.

Do not infer a durable preference from one request. Change the memory only when
the user explicitly asks to remember or forget. Consolidate equivalent entries,
remove duplicates, and retain project-specific context separately. Reuse an
existing project `DESIGN.md`; create or update one only when persistence of a
design identity/system or coordination across multiple surfaces is requested.
