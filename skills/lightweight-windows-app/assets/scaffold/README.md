## How to install

1. Download `__APP__-Setup-x.y.z.exe` from the <a href="__REPO_URL__/releases/latest">releases page</a>.
2. Open the file. Installation takes a few seconds and asks for no administrator password.

The installer has no digital signature yet, so Windows may show a SmartScreen warning. If so, choose **More info** and then **Run anyway**.

Requires Windows 10 or 11.
